# PinWindow — 窗口一键置顶工具

**右键任意窗口右上角的「最小化 / 最大化 / 关闭」三个按钮区域中的任意一个位置，即可把该窗口置顶到最前面；再次右键即可取消置顶。**

当前版本：**1.1**（汉化二创版）

## 关于本项目

本项目是在开源项目 **[helliong/PinWindow](https://github.com/helliong/pinWindow)** 的基础上二次开发的中文汉化改进版：

- **原作者**：[helliong](https://github.com/helliong)（PinWindow 原项目作者）
- **本版本维护者**：[yyfaded](https://github.com/yyfaded)
- **开源仓库**：[yyfaded/PinWindow](https://github.com/yyfaded/PinWindow)

原版界面为俄语/英语，本项目已汉化为简体中文，并修复了 Electron 类窗口（如豆包、Chrome）右键触发失效的问题，增加了多种按键触发选项与托盘图标开关，同时更新检测已独立接入个人仓库。

## 下载哪个版本

| 文件 | 适用电脑 | 说明 |
|---|---|---|
| `PinWindow-win-x64.exe` | 绝大多数 64 位电脑（Windows 10/11） | 主流，推荐 |
| `PinWindow-win-arm64.exe` | ARM 架构笔记本（骁龙 X、Surface Pro X 等） | 新版轻薄本 |
| `PinWindow-win-x86.exe` | 老式 32 位电脑 | 2015 年以前的旧设备 |

> 注意：本版本为**框架依赖版**，需要电脑装有 **.NET 10 Desktop Runtime**（Windows 10/11 默认未安装）。  
> 下载安装：https://dotnet.microsoft.com/download/dotnet/10.0 （选 ".NET Desktop Runtime"）

## 使用方法

1. 双击 exe 运行（程序在后台静默运行，启动时若托盘图标开启可在托盘看到）
2. **右键**（或设置的自定义按键）任意窗口右上角的 **— □ ×** 三个按钮区域之一 → 窗口置顶；**再次点击** → 取消置顶
3. 再次双击 exe 可随时打开设置窗口（也可通过系统托盘双击图标打开设置）

## 功能特性

- **右键即置顶**：右键窗口右上角三按钮区域（最小化 / 最大化还原 / 关闭）任意位置即可置顶，无需额外悬浮按钮
- **按键自由选择**：默认鼠标右键，可自定义为鼠标中键、侧键 1（后退）、侧键 2（前进）或任意鼠标键
- **单置顶机制**：同一时刻只有一个窗口置顶——置顶新窗口时，自动取消旧窗口的置顶；再点击当前置顶窗口则取消置顶
- **置顶保持**：每 500ms 自动保持置顶窗口在最顶层，防止其他应用临时全屏或置顶盖住
- **取消置顶智能让位**：取消置顶时窗口回到原位并下挪一位，让出位置，其他普通窗口可正常点击激活
- **支持所有 Windows 窗口**：普通 Win32 窗口、Electron 应用（豆包、Chrome、VSCode 等）、UWP 应用
- **全局快捷键**：可自定义（如 Ctrl+Alt+T），默认设为"无"，不占用系统快捷键
- **托盘图标开关**：设置中支持开关系统托盘（任务栏隐藏图标）显示，关闭后可通过再次双击 exe 唤起设置
- **多语言界面**：简体中文 / English / Русский（默认简体中文）
- **开机自启动**：可在设置中一键开启/关闭
- **单实例运行**：重复启动只唤起设置窗口，不重复常驻
- **独立更新检测**：自动检测个人仓库新版本发布，不再提示原作者仓库更新
- **低资源占用**：约 270KB，内存占用低，后台静默省电

## 设置项说明

- **语言**：简体中文 / English / Русский（默认简体中文）
- **触发置顶鼠标按键**：鼠标右键 (推荐) / 鼠标中键 / 鼠标侧键 1 / 鼠标侧键 2 / 任意按键
- **键盘全局快捷键**：Ctrl/Alt/Shift/Win 组合键 + 字母/功能键（默认"无"）
- **在系统托盘(任务栏隐藏图标)中显示图标**：开启或关闭（关闭后再次双击 exe 可唤出设置）
- **开机时自动启动 PinWindow**：随 Windows 系统启动
