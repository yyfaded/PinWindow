# PinWindow — 窗口一键置顶工具

**右键任意窗口右上角的「最小化 / 最大化 / 关闭」三个按钮区域中的任意一个位置，即可把该窗口置顶到最前面；再次右键即可取消置顶。**

当前版本：**1.0**（汉化二创版）

## 关于本项目

本项目是在开源项目 **[helliong/PinWindow](https://github.com/helliong/pinWindow)** 的基础上二次开发的中文汉化改进版：

- **原作者**：[helliong](https://github.com/helliong)（PinWindow 原项目作者）
- **本版本**：简体中文汉化 + 多项功能修复与改进（详见下方功能特性）

原版界面为俄语/英语，本项目已汉化为简体中文，并修复了 Electron 类窗口（如豆包、Chrome）右键触发失效的问题，同时针对 Windows 窗口层级做了大量稳定性改进。

## 使用方法

1. 双击 exe 运行（程序在后台工作，第一次双击会弹出设置窗口）
2. **右键**任意窗口右上角的 **— □ ×** 三个按钮区域之一 → 窗口置顶；**再右键一次** → 取消置顶
3. 再次双击 exe 可随时打开设置窗口

## 功能特性

- **右键即置顶**：右键窗口右上角三按钮区域（最小化 / 最大化还原 / 关闭）任意位置即可置顶，无需额外按钮
- **单置顶机制**：同一时刻只有一个窗口置顶——置顶新窗口时，自动取消旧窗口的置顶；再右键当前置顶窗口则取消置顶
- **置顶保持**：每 500ms 自动把置顶窗口保持到最顶层，防止其他应用（如全屏/激活时抢置顶的程序）盖住它
- **取消置顶智能让位**：取消置顶时窗口回到原位并下挪一位，让出位置，其他窗口可以正常点击激活
- **支持所有 Windows 窗口**：普通窗口、Electron 应用（豆包、Chrome、ChatGPT 等）、UWP 应用
- **多种触发方式**：默认鼠标右键，可改为中键 / 侧键 / 任意按键
- **全局快捷键**：可自定义，按一下即可置顶当前窗口（默认关闭）
- **三语言界面**：简体中文 / English / Русский（默认简体中文）
- **开机自启动**：默认开启，可在设置中关闭
- **单实例运行**：重复启动只弹出设置窗口，不重复运行
- **低资源占用**：约 275KB，后台静默运行

## 设置项

- **触发按键**：右键（默认）/ 中键 / 侧键1 / 侧键2 / 任意按键
- **全局快捷键**：Ctrl/Alt/Shift/Win 组合 + 按键（默认关闭）
- **语言**：简体中文 / English / Русский（默认简体中文）
- **开机自启动**：默认开启，可关闭
- **托盘图标**：默认隐藏，可打开（开启后可在系统托盘隐藏图标中看到）

## 常见问题

**Q：双击 exe 没有反应？**
A：程序已经在后台运行。设置窗口的打开方式是"再次双击 exe"；如果连设置窗口都打不开，说明程序未安装 .NET 10 运行时。

**Q：右键按钮没有置顶反应？**
A：确认触发按键设置（默认右键）。部分特殊窗口（如全屏游戏、自绘标题栏应用）可能需要用设置里的"全局快捷键"方式置顶。

**Q：取消置顶后点其他窗口没反应？**
A：如果两个窗口位置重叠，上面的窗口会盖住下面的——被盖住的部分点击永远命中上面的窗口（Windows 对所有软件都一样的规则）。取消置顶后把窗口错开摆放即可正常点击。
